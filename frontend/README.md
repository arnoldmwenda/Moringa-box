# Google Drive Clone - Frontend Client

React user interface built with Redux Toolkit and mobile-friendly responsive layout.

## Setup & Running Instructions

**Install Dependencies:**
```bash
cd frontend
npm install
```
**Setup environment variables:**
```bash
cp .env.example .env
```

**Start development server:**
```bash
npm start
```

**Return to the root directory:**
```bash
cd..
```
